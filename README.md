📦 Nassau Candy Distributor – Power BI Dashboard
Overview
This Power BI report provides an end-to-end analysis of Nassau Candy Distributor's sales and logistics operations. It covers revenue performance, order fulfillment, shipping efficiency, and regional route breakdowns — giving stakeholders a clear view of business health and delivery operations.

📊 Report Pages
1. Overview
A high-level summary of business performance across regions and divisions.

Total Revenue by Region & Division (Clustered Bar Chart) — compares revenue contribution across geographic regions, broken down by product division
Revenue Trend over Time (Line Chart) — tracks revenue movement month over month
Order Distribution (Donut Chart) — shows order share across categories
Slicers: Region · Ship Mode · Year


2. Shipping Analysis
Focused on delivery performance and fulfillment efficiency.

Orders by Ship Mode (Bar Chart) — volume comparison across shipping methods
State-level Breakdown (Pivot Table) — granular shipping data by state/province
Column Chart — performance comparison across categories
Geographic Map — visual distribution of shipments by location
Key Metrics: Avg Days to Ship · On-Time Rate % · Delayed Orders · Total Orders
Slicers: Region · Ship Mode · State/Province


3. Route Drilldown
Deep-dive into individual shipping routes and delivery patterns.

Bar Chart — route-level order/revenue comparison
Scatter Chart — correlation analysis (e.g. order volume vs. days to ship)
Detail Table — granular row-level data per route/city
Slicers: Division · Region · Ship Mode · Year (multi-filter enabled)

🚀 How to Use

Download the Nassau_Candy_Distributor.pbix file
Open with Power BI Desktop (free download at powerbi.microsoft.com)
Use the slicers on each page to filter by Region, Year, Ship Mode, or Division
Click on any visual to cross-filter other visuals on the page
Use Route Drilldown for deep analysis of specific delivery corridors


🛠️ Requirements

Power BI Desktop (latest version recommended)
No live data connection required — data is embedded in the .pbix file
